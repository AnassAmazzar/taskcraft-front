# TaskCraft Frontend

Template initial React + TypeScript pour la plateforme SaaS TaskCraft.

## Commandes

```bash
npm install
npm run dev
npm run build
```

## Structure

- `src/components` : composants UI reutilisables.
- `src/data` : donnees mockees avant integration API.
- `src/types.ts` : types metier partages cote front.
- `src/styles.css` : design system initial et responsive.
